# Overview

This section provides orientation for ngGONG High Level Software.

## Purpose

ngGONG HLS documentation should describe the software architecture, operational expectations, development practices, integration points, and design decisions needed by engineers and project stakeholders.

## Scope

Initial documentation should cover:

- System context and major software responsibilities.
- Design documents for early architecture and interfaces.
- Software development planning and repository practices.
- Decisions that affect the multi-repository HLS project.

## Audience

Primary audiences include NSO software developers, project engineers, reviewers, operators, and future maintainers.
