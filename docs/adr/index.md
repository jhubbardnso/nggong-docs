# Architectural Decision Records

Architectural decision records capture important technical decisions and their rationale.

## ADR Template

Copy this structure when adding a new ADR:

```markdown
# ADR NNNN: Title

## Status

Proposed | Accepted | Superseded

## Context

What forces, constraints, or project facts led to this decision?

## Decision

What decision was made?

## Consequences

What becomes easier, harder, or constrained because of this decision?
```
